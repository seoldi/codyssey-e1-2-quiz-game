# E1-2 · 나만의 퀴즈 게임 (Python)

터미널에서 동작하는 퀴즈 게임입니다. 퀴즈 풀기 · 추가 · 목록 · 최고 점수 확인을 지원하고, 프로그램을 종료해도 퀴즈와 최고 점수가 `state.json`에 남습니다.

## 1) 프로젝트 개요
- 코디세이 올인원 1기 입학 연수 **E1-2 「컴퓨터에게 명령 내리는 말(파이썬) 처음 배우기」** 미션 결과물입니다.
- Python 기본 문법(변수 · 자료형 · 조건문 · 반복문 · 함수)과 클래스(`Quiz`, `QuizGame`)로 터미널 게임을 구현했습니다.
- 데이터는 JSON 파일(`state.json`)에 UTF-8로 저장하고, 파일이 없거나 손상돼도 실행되도록 `try / except`로 처리했습니다.
- 기능 단위로 커밋하고, 브랜치(`feature/play`)에서 작업해 `main`에 병합하는 Git 흐름을 사용했습니다.
- 외부 라이브러리 없이 표준 라이브러리(`json`, `os`, `pathlib`)만 사용합니다. (Python 3.10 이상)

## 2) 퀴즈 주제와 선정 이유
**주제: Git · Docker · 터미널 기초**

바로 앞 미션(E1-1 「개발자용 작업실 꾸미기」)에서 배운 내용을 **복습하고 시험에 대비**하려고 선택했습니다. 퀴즈를 직접 만들면서 개념(commit/push, 볼륨, 포트 매핑, 권한 755, 상대 경로 등)을 다시 정리할 수 있고, 퀴즈 추가 기능으로 이후에도 문제를 계속 늘릴 수 있습니다. 기본으로 8문제가 들어 있습니다.

## 3) 실행 방법
```bash
python main.py
```
- 요구: Python 3.10 이상 (개발·검증: Python 3.14.2)
- 첫 실행에는 `state.json`이 없어서 기본 퀴즈 8개로 시작하고, 종료 시 `state.json`이 자동으로 만들어집니다.

## 4) 기능 목록
- [x] **퀴즈 풀기**: 저장된 퀴즈를 순서대로 출제 → 정답 입력 → 정답/오답 안내 → 결과(점수) 표시
- [x] **퀴즈 추가**: 문제, 선택지 4개, 정답 번호를 입력해 등록 (즉시 파일에 저장)
- [x] **퀴즈 목록**: 등록된 문제 목록 확인 (퀴즈가 없으면 안내)
- [x] **점수 확인**: 최고 점수 확인, 퀴즈를 풀 때마다 비교·갱신해 파일에 저장 (아직 안 풀었으면 안내)
- [x] **데이터 유지**: 종료 후 다시 실행해도 퀴즈와 최고 점수 유지
- [x] **예외 처리**: 아래 표 참고

### 입력/예외 처리
| 상황 | 동작 |
|---|---|
| 입력 앞뒤 공백 (` 1 `) | 공백을 제거하고 처리 |
| 숫자가 아닌 입력 (`abc`) | 안내 후 재입력 |
| 범위 밖 숫자 (메뉴 9, 정답 0) | 안내 후 재입력 |
| 빈 입력 (Enter) | 안내 후 재입력 |
| `Ctrl+C` / 입력 스트림 종료(`EOFError`) | 안내 후 **저장하고 정상 종료** |
| `state.json`이 없음 | 기본 퀴즈로 시작 |
| `state.json`이 손상됨 (깨진 JSON, 키 누락, 잘못된 값) | 안내 후 기본 퀴즈로 **복구** |
| 파일 읽기/쓰기 오류 (`OSError`) | 안내 후 계속 실행 |

## 5) 파일 구조
```text
E1-2_quiz-game/
├─ main.py        # 프로그램 전체 (Quiz, QuizGame 클래스, 입력 함수)
├─ README.md      # 이 문서
├─ .gitignore     # state.json, 캐시, 비밀값 파일 등 제외
└─ state.json     # 실행하면 자동 생성되는 데이터 파일 (Git에는 올리지 않음)
```

### `main.py` 구성
| 이름 | 종류 | 역할 |
|---|---|---|
| `Quiz` | 클래스 | 퀴즈 한 문제 (`question`, `choices`, `answer`). `show()`, `is_correct()`, `to_dict()`, `from_dict()` |
| `QuizGame` | 클래스 | 게임 전체 관리 (`quizzes`, `best_score`). 메뉴 · 풀기 · 추가 · 목록 · 점수 · 저장/불러오기 · 실행 루프 |
| `read_number()` | 함수 | 범위가 있는 숫자 입력 (공백 · 변환 실패 · 범위 · 빈 입력 검사) |
| `read_text()` | 함수 | 비어 있지 않은 문자열 입력 |
| `create_default_quizzes()` | 함수 | 기본 퀴즈 8개 생성 |

## 6) 데이터 파일 설명 (`state.json`)
- **경로**: 프로젝트 루트 `state.json` (`main.py`와 같은 폴더)
- **인코딩**: UTF-8 (`ensure_ascii=False`로 한글을 그대로 저장)
- **역할**: 퀴즈 목록과 최고 점수를 저장해 프로그램을 다시 실행해도 유지
- **저장 시점**: 퀴즈 추가 직후 / 최고 점수 갱신 직후 / 프로그램 종료 시(`Ctrl+C` 포함)
- **안전한 저장**: 임시 파일(`state.json.tmp`)에 먼저 쓴 뒤 교체(`os.replace`)해서, 저장 도중에 끊겨도 기존 파일이 깨지지 않습니다.

스키마:
```json
{
    "quizzes": [
        {
            "question": "변경 내용을 '내 컴퓨터'에 버전으로 기록하는 Git 명령은?",
            "choices": ["git push", "git commit", "git clone", "git pull"],
            "answer": 2
        }
    ],
    "best_score": 100
}
```

| 키 | 타입 | 설명 |
|---|---|---|
| `quizzes` | 리스트 | 퀴즈 목록 |
| `quizzes[].question` | 문자열 | 문제 (비어 있으면 안 됨) |
| `quizzes[].choices` | 문자열 4개 리스트 | 선택지 |
| `quizzes[].answer` | 정수 1~4 | 정답 번호 |
| `best_score` | 정수 또는 `null` | 최고 점수(100점 만점). 아직 안 풀었으면 `null` |

> `state.json`은 실행마다 바뀌는 데이터라 `.gitignore`로 제외했습니다. 위 스키마가 곧 파일 형식입니다.

## 7) 실행 예시
```text
========================================
        나만의 퀴즈 게임
========================================
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
========================================
선택: 4
아직 퀴즈를 풀지 않았습니다. 먼저 퀴즈를 풀어 보세요.
```

```text
퀴즈를 시작합니다! (총 8문제)
----------------------------------------
[문제 1]
변경 내용을 '내 컴퓨터'에 버전으로 기록하는 Git 명령은?

1. git push
2. git commit
3. git clone
4. git pull
정답 입력 (1~4): 2
정답입니다!
...
========================================
결과: 8문제 중 5문제 정답! (62점)
========================================
새로운 최고 점수입니다!
```

```text
저장된 데이터를 불러왔습니다. (퀴즈 9개, 최고 점수 100점)    # 종료 후 재실행해도 유지
⚠ 데이터 파일이 손상되어 기본 퀴즈로 복구합니다.               # state.json이 깨졌을 때
```

> clone·pull 실습: 별도 폴더에 clone한 저장소에서 이 줄을 추가해 push하고, 원래 작업 폴더에서 `git pull`로 가져왔습니다.
